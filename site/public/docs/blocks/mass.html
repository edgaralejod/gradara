Block reference › Translational

Mass

A sliding mass with two flanges: m·a = f_a + f_b.

Description

A sliding point mass with two flanges, both at the position of the mass. It has no friction; add a Damper to Fixed (translational) for viscous losses.

Ports

Conserving terminals

PortDomainDescription
a flange_atranslationalFlange a. Force into the flange is positive.
b flange_btranslationalFlange b, at the same position as flange_a.

Parameters

ParameterDefaultDescription
Mass m1 kg
≥ 0		Mass, in kilograms. Zero or positive.

Equations

flange_a.s = flange_b.s = s
v = ds/dt
m · dv/dt = flange_a.f + flange_b.f

Implementation

Instantiates Modelica.Mechanics.Translational.Components.Mass from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No friction, no end stops, and no length (both flanges at one point). For stops and friction, use Mass with stops.
