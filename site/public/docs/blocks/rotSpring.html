Torsion spring

Linear torsion spring: τ = c·(φ_rel − φ_rel0).

Description

A linear torsion spring between two flanges. Connect it between two inertias to model shaft elasticity, or between an inertia and Fixed (rotational) to model a return spring.

Ports

Conserving terminals

PortDomainDescription
a flange_arotationalFlange a. Receives −τ.
b flange_brotationalFlange b. Receives τ, the spring torque.

Parameters

ParameterDefaultDescription
Stiffness c10000 N·m/rad
≥ 0		Torsional stiffness, in N·m/rad. Zero or positive.
Unstretched angle phi_rel00 radRelative angle at which the spring exerts no torque, in radians.

Equations

φ_rel = flange_b.phi − flange_a.phi
τ = c · (φ_rel − phi_rel0)
flange_b.tau = τ, flange_a.tau = −τ

Implementation

Instantiates Modelica.Mechanics.Rotational.Components.Spring from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No damping and no mass. A stiff spring between two inertias makes the model stiff; add a little damping in parallel.
