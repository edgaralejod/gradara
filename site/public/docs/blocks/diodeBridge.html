Diode bridge

Single-phase full-wave diode rectifier.

Description

A single-phase full-wave (two-pulse) rectifier of four ideal diodes. dc_p is fed from ac_p and ac_n through two diodes; dc_n returns through the other two.

There is no smoothing capacitor; add one across dc_p and dc_n if needed.

Ports

Conserving terminals

PortDomainDescription
ac+ ac_pelectricalAC terminal 1.
ac− ac_nelectricalAC terminal 2.
dc+ dc_pelectricalDC positive terminal (common cathode of the upper diodes).
dc− dc_nelectricalDC negative terminal (common anode of the lower diodes).

Parameters

Equations

With a resistive load and no capacitor: dc_p.v − dc_n.v ≈ |ac_p.v − ac_n.v|

Implementation

Instantiates Modelica.Electrical.PowerConverters.ACDC.DiodeBridge2Pulse from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Ideal diodes with the knee voltage fixed at 0 V: no forward drop, reverse recovery, or junction capacitance.
