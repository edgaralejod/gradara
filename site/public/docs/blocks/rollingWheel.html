Rolling wheel

Converts rotation to translation without slip: v = r·ω.

Description

An ideal wheel that rolls without slip: it converts the rotation of the axle into translation of the contact point. Use it to connect a rotational drivetrain to a vehicle mass.

Ports

Conserving terminals

PortDomainDescription
rot flangeRrotationalRotational flange (the axle). Torque into it is positive.
lin flangeTtranslationalTranslational flange (the road contact). Force into it is positive.

Parameters

ParameterDefaultDescription
Radius radius0.3 m
≥ 0		Wheel radius, in meters. Must be positive.

Equations

flangeT.s = radius · flangeR.phi
0 = radius · flangeT.f + flangeR.tau

Implementation

Instantiates Modelica.Mechanics.Rotational.Components.IdealRollingWheel from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No wheel inertia, rolling resistance, or tire slip. Add Inertia (ideal) on the axle for the wheel’s own inertia.
