Ideal gear

Lossless gear: φ_a = ratio·φ_b.

Description

A lossless gear fixed to the housing, with no inertia, elasticity, or backlash. Flange a turns ratio times as far as flange b, and the torque is scaled by the same factor, so power is conserved.

Ports

Conserving terminals

PortDomainDescription
a flange_arotationalInput side flange. Angle φ_a = ratio · φ_b.
b flange_brotationalOutput side flange.

Parameters

ParameterDefaultDescription
Ratio ratio2Transmission ratio φ_a/φ_b. A value above 1 reduces speed and raises torque at flange_b; a negative value reverses direction.

Equations

flange_a.phi = ratio · flange_b.phi
0 = ratio · flange_a.tau + flange_b.tau

Implementation

Instantiates Modelica.Mechanics.Rotational.Components.IdealGear from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No friction, efficiency loss, backlash, or tooth stiffness. Add Backlash or Torsion spring on either side for those effects.

Tips

  • An inertia J behind the gear appears as J/ratio² at flange_a.
