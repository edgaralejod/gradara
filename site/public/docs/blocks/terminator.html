Terminator

Cap an unused output so the sheet stays tidy.

Description

Caps an output you do not use, so the sheet shows it is left open on purpose. It has no effect on the simulation.

Ports

Inputs

PortDomainDescription
usignalSignal to discard.

Implementation

The block’s Modelica equations:

Real unused;
unused = u;

Assumptions and limitations

  • The signal is still recorded as the driving block’s output.
