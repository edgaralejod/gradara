Fixed heat flow

Injects a constant heat flow into its port.

Description

Injects a constant heat flow into whatever its port is connected to, whatever the port temperature. Use it for a steady power dissipation such as a component’s losses.

Ports

Conserving terminals

PortDomainDescription
Q portthermalHeat port. The block delivers Q_flow out of this port into the connected network.

Parameters

ParameterDefaultDescription
Heat flow Q_flow10 WHeat flow, in watts. Positive heats the connected network; negative cools it.

Equations

port.Q_flow = −Q_flow

Implementation

Instantiates Modelica.Thermal.HeatTransfer.Sources.FixedHeatFlow from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • A network fed only by heat-flow sources, with no heat capacity or fixed temperature, has no defined temperature.
