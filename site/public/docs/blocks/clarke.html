Clarke transform

Amplitude-invariant three-phase to stationary-frame current transform.

Description

Converts three phase currents into the two-axis stationary frame (α, β), using the amplitude-invariant form: a balanced set of phase currents with peak Î gives α and β with the same peak Î.

Use it with Park transform to turn measured motor currents into d/q currents.

Ports

Inputs

PortDomainDescription
a iasignalPhase a current, in amperes.
b ibsignalPhase b current, in amperes.
c icsignalPhase c current, in amperes.

Outputs

PortDomainDescription
α alphasignal · Aα-axis current, in amperes, aligned with phase a.
β betasignal · Aβ-axis current, in amperes, 90° ahead of α.

Equations

alpha = (2 · ia − ib − ic)/3
beta = (ib − ic)/√3

Implementation

The block’s Modelica equations:

alpha = (2*ia-ib-ic)/3;
beta = (ib-ic)/sqrt(3);

Assumptions and limitations

  • Any zero-sequence (common-mode) component ia + ib + ic is discarded; it does not appear in either output.

Tips

  • All three currents are used. Connect ic even when the phases sum to zero; it is not reconstructed from ia and ib.
