Block reference › Magnetic

Flux source

A constant magnetic flux.

Description

Forces a constant magnetic flux through itself, whatever the magnetic potential difference across it.

Ports

Conserving terminals

PortDomainDescription
+ port_pmagneticPositive magnetic port. The flux Phi enters here.
− port_nmagneticNegative magnetic port. The flux Phi leaves here.

Parameters

ParameterDefaultDescription
Flux Phi0.001 WbMagnetic flux, in webers. Any real value.

Equations

port_p.Φ = Phi
port_p.Φ + port_n.Φ = 0

Implementation

Instantiates Modelica.Magnetic.FluxTubes.Sources.ConstantMagneticFlux from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • An ideal source. Do not connect it in series with a winding or another flux source.
