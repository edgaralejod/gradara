Block reference › Thermal

Heat flow source

Injects the input heat flow (W) into its port.

Description

Injects the heat flow given by an input signal into whatever its port is connected to. Use it to feed computed losses, for example electrical power dissipation, into a thermal model.

Ports

Inputs

PortDomainDescription
Q Q_flowsignalHeat flow to inject, in watts. Positive heats the connected network.

Conserving terminals

PortDomainDescription
Q portthermalHeat port. The block delivers Q_flow out of this port.

Equations

port.Q_flow = −Q_flow

Implementation

Instantiates Modelica.Thermal.HeatTransfer.Sources.PrescribedHeatFlow from the Modelica Standard Library 4.1.0. MSL documentation

Tips

  • Pair it with Power sensor to turn a component’s electrical loss into heat.
