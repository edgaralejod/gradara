3-phase inductor

Inductor in each phase.

  • 3-phase
  • Modelica Standard Library
  • 2 ports
  • 1 parameter

Description

Three independent linear inductors, one in each phase between plug_p and plug_n, with no coupling between phases.

Example

Three-phase loads A 10 V three-phase supply into a resistive star load, a series R–L star load, and a capacitor bank in delta.

Ports

Conserving terminals 2

  • +plug_p3-phase

    Three-phase plug (phases a, b, c). Current into plug_p is counted as positive.

  • −plug_n3-phase

    Three-phase plug (phases a, b, c).

Parameters

  • Inductance per phaseL0.01 H

    ≥ 0

    Inductance of each phase, in henries. Positive.

Equations

Modelica
vk = L · d(ik)/dt for k = a, b, c

Implementation

Modelica Standard Library 4.1.0Modelica.Electrical.Polyphase.Basic.Inductor
MSL documentation

Assumptions and limitations

  • No mutual coupling, saturation, or winding resistance.

Tips

  • Use it as a line reactor or grid impedance, often in series with a 3-phase resistor.
