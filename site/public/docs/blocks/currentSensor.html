Current sensor

Measures branch current with zero series voltage drop; positive from + to −.

Description

Measures the current in a branch and outputs it as a signal. Place it in series; it has no voltage drop.

Ports

Outputs

PortDomainDescription
A ysignal · AMeasured current, in amperes. Positive when current flows from p to n through the sensor.

Conserving terminals

PortDomainDescription
+ pelectricalPin where the measured current enters.
− nelectricalPin where the measured current leaves.

Equations

y = p.i
p.v = n.v
p.i + n.i = 0

Assumptions and limitations

  • Ideal: zero resistance, no bandwidth limit or noise.

Tips

  • If the reading has the wrong sign, swap p and n.

Examples

Used in the shipped examples Buck converter · Ideal switches, EV drivetrain, 480 VAC → 24 VDC flyback. Open them from Examples in the app.
