3-phase voltage sensor

Phase voltages between plug + and plug −.

Description

Measures the three voltages between corresponding phases of plug_p and plug_n. It draws no current.

For phase-to-neutral voltages, connect plug_n to a Star point tied to the neutral.

Ports

Outputs

PortDomainDescription
vasignalplug_p.a.v − plug_n.a.v, in volts.
vbsignalplug_p.b.v − plug_n.b.v, in volts.
vcsignalplug_p.c.v − plug_n.c.v, in volts.

Conserving terminals

PortDomainDescription
+ plug_p3-phaseThree-phase plug (phases a, b, c), positive side.
− plug_n3-phaseThree-phase plug (phases a, b, c), reference side.

Equations

vk = plug_p.k.v − plug_n.k.v for k = a, b, c
plug_p.k.i = plug_n.k.i = 0

Implementation

Instantiates Modelica.Electrical.Polyphase.Sensors.VoltageSensor from the Modelica Standard Library 4.1.0. MSL documentation
