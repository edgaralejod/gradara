Block reference › 3-phase

Phase a tap

Connects phase a of a 3-phase plug to a single-phase pin.

Description

Taps phase a of a three-phase plug as a single-phase pin, so single-phase blocks can connect to it. The other phases carry no current through this block.

Ports

Conserving terminals

PortDomainDescription
abc plug_p3-phaseThree-phase plug (phases a, b, c).
a pin_pelectricalSingle-phase pin at the potential of phase a.

Equations

pin_p.v = plug_p.a.v
plug_p.a.i = −pin_p.i, plug_p.b.i = plug_p.c.i = 0

Implementation

Instantiates Modelica.Electrical.Polyphase.Basic.PlugToPin_p from the Modelica Standard Library 4.1.0. MSL documentation
