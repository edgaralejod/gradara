MMF source

A constant magnetomotive force (for example a permanent magnet model).

Description

A constant magnetomotive force between its ports, whatever flux passes through. Use it for an idealized coil with fixed ampere-turns or, with a series reluctance, a simple permanent-magnet model.

Ports

Conserving terminals

PortDomainDescription
+ port_pmagneticPositive magnetic port, held V_m above port_n.
− port_nmagneticNegative magnetic port.

Parameters

ParameterDefaultDescription
Magnetomotive force V_m100 AMagnetomotive force, in amperes (ampere-turns). Any real value.

Equations

port_p.V_m − port_n.V_m = V_m
port_p.Φ + port_n.Φ = 0

Implementation

Instantiates Modelica.Magnetic.FluxTubes.Sources.ConstantMagneticPotentialDifference from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • An ideal source: no internal reluctance. Connect a reluctance in series to model a magnet’s own reluctance.
