Thyristor

Ideal thyristor: turns on at a fire pulse when forward biased, off when current reverses.

Description

An ideal thyristor (SCR). It turns on when fire is true while the anode–cathode voltage is forward, then stays on after fire goes false until its current falls to zero.

Fire is level-sensitive: while fire stays true the thyristor behaves like an ideal diode.

Ports

Inputs

PortDomainDescription
g fireBooleanGate command (Boolean). A true value turns the thyristor on if it is forward biased.

Conserving terminals

PortDomainDescription
A pelectricalAnode. Current into p is counted as positive.
K nelectricalCathode.

Parameters

ParameterDefaultDescription
On resistance Ron0.00001 Ω
≥ 0		On resistance, in ohms: the slope of the conducting branch. 0 or more; the default 10 µΩ is near-ideal.
Off conductance Goff0.00001 S
≥ 0		Off conductance, in siemens: the slope of the blocking branch, so the leakage is Goff · v. 0 or more; the default 10 µS leaks 10 µA per volt.

Equations

v = p.v − n.v, i = p.i
Off: i = Goff · v; on: v = Ron · i
off = (s < 0) or (pre(off) and not fire), where s < 0 means v < 0 while off, or i < 0 while on

Implementation

Instantiates Modelica.Electrical.Analog.Ideal.IdealThyristor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Knee voltage fixed at 0 V. No holding or latching current, gate current, dv/dt triggering, turn-off time, or reverse recovery.

Tips

  • Short fire pulses are enough to trigger it; delay them from the voltage zero crossing to set the firing angle.
