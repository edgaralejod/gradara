Unit delay

One-sample delay.

Description

Delays its input by one sample. At each sample instant the output takes the input stored at the previous instant.

Ports

Inputs

PortDomainDescription
usignalInput signal, read at each sample instant.

Outputs

PortDomainDescription
ysignalOutput signal, held between samples.

Parameters

ParameterDefaultDescription
Sample period Ts0.001 s
≥ 0.0001		Sample period, in seconds. At least 0.0001 s (default 1 ms).

Equations

At t = k · Ts, k = 0, 1, 2, …:
y[k] = u[k − 1], with u[−1] = 0

Implementation

The block’s Modelica equations:

discrete Real stored(start=0, fixed=true);
when sample(0, Ts) then
  y = pre(stored);
  stored = u;
end when;

Assumptions and limitations

  • Samples are taken at fixed multiples of Ts from time 0; there is no offset or external trigger.
  • The initial output is always 0.
