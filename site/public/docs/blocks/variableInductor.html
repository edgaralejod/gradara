Variable inductor

Inductance set by the input signal.

Description

An inductor whose inductance is set by an input signal. The flux linkage is inductance times current, so changing the inductance at fixed flux changes the current.

Ports

Inputs

PortDomainDescription
LsignalInductance, in henries. Must stay 0 or more.

Conserving terminals

PortDomainDescription
+ pelectricalPositive pin. Current into p is counted as positive.
− nelectricalNegative pin.

Parameters

ParameterDefaultDescription
Minimum inductance Lmin1e-12 H
≥ 0		Lower bound on the inductance used in the equations, in henries. Keeps the model solvable when the input reaches 0.

Equations

v = p.v − n.v, i = p.i, p.i + n.i = 0
Psi = max(L, Lmin) · i
v = dPsi/dt

Implementation

Instantiates Modelica.Electrical.Analog.Basic.VariableInductor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The simulation stops with an error if the input goes negative.
  • The initial current is not fixed by the block.
