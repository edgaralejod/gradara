Power

Raise a signal to a real exponent.

Description

Raises its input to a constant real exponent.

Ports

Inputs

PortDomainDescription
usignalBase.

Outputs

PortDomainDescription
ysignalOutput signal, u raised to Exponent.

Parameters

ParameterDefaultDescription
Exponent n2The exponent. Any real number; 2 squares the input, 0.5 takes the square root.

Equations

y = u^n

Implementation

The block’s Modelica equations:

y = u^n;

Assumptions and limitations

  • The result is undefined for a negative u with a non-integer n, and for u = 0 with a negative n; the simulation then fails. Unlike Sqrt, the input is not clipped.
