Sqrt

Square root of a non-negative input.

Description

Outputs the square root of its input. A negative input is treated as 0.

Ports

Inputs

PortDomainDescription
usignalInput signal.

Outputs

PortDomainDescription
ysignalOutput signal, √u for u ≥ 0 and 0 for u < 0.

Equations

y = √max(0, u)

Implementation

The block’s Modelica equations:

y = sqrt(max(0, u));

Assumptions and limitations

  • Negative inputs are clipped to 0 silently, with no warning.
