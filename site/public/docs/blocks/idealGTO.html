GTO thyristor

Gate turn-off thyristor: conducts while fire is true and forward biased.

Description

An ideal gate turn-off thyristor: it conducts only while fire is true and the device is forward biased, and turns off as soon as fire goes false.

Use it as a generic unidirectional power switch (IGBT or GTO); add an antiparallel diode for reverse current.

Ports

Inputs

PortDomainDescription
g fireBooleanGate command (Boolean). True allows forward conduction; false blocks.

Conserving terminals

PortDomainDescription
A pelectricalAnode. Current into p is counted as positive.
K nelectricalCathode.

Parameters

ParameterDefaultDescription
On resistance Ron0.00001 Ω
≥ 0		On resistance, in ohms: the slope of the conducting branch. 0 or more; the default 10 µΩ is near-ideal.
Off conductance Goff0.00001 S
≥ 0		Off conductance, in siemens: the slope of the blocking branch, so the leakage is Goff · v. 0 or more; the default 10 µS leaks 10 µA per volt.

Equations

v = p.v − n.v, i = p.i
Off: i = Goff · v; on: v = Ron · i
off = (s < 0) or not fire, where s < 0 means v < 0 while off, or i < 0 while on

Implementation

Instantiates Modelica.Electrical.Analog.Ideal.IdealGTOThyristor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Knee voltage fixed at 0 V. Blocks reverse current even when fire is true. No switching times, tail current, or switching losses.
  • Turning it off with inductive current and no freewheeling path forces the current into Goff, which produces a very large voltage.
