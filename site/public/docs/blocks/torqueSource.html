Torque source

Applies the input signal as torque to the flange.

Description

Applies the input signal as a torque to the flange, reacting against the housing. Use it for an actuator whose torque is computed by a controller or a signal source.

Ports

Inputs

PortDomainDescription
τ tausignalTorque to apply, in N·m. A positive value accelerates the flange in the positive direction.

Conserving terminals

PortDomainDescription
shaft flangerotationalFlange the torque acts on.

Equations

flange.tau = −tau

Implementation

Instantiates Modelica.Mechanics.Rotational.Sources.Torque from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The reaction torque goes to the housing; there is no support flange.
