Relative speed sensor

Speed of flange b relative to flange a.

Description

Measures the angular velocity of flange b relative to flange a, without transmitting torque. Use it to monitor slip across a clutch or twist rate across a spring.

Ports

Outputs

PortDomainDescription
Δω w_relsignalRelative angular velocity, in rad/s.

Conserving terminals

PortDomainDescription
a flange_arotationalReference flange. No torque is exchanged.
b flange_brotationalMeasured flange. No torque is exchanged.

Equations

w_rel = d(flange_b.phi − flange_a.phi)/dt
flange_a.tau = flange_b.tau = 0

Implementation

Instantiates Modelica.Mechanics.Rotational.Sensors.RelSpeedSensor from the Modelica Standard Library 4.1.0. MSL documentation
