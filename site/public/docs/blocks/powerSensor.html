Power sensor

Instantaneous power: current path pc→nc, voltage across pv–nv.

Description

Measures instantaneous electrical power as the product of a branch current and a voltage. The current path goes in series through pc and nc; the voltage is sensed between pv and nv.

Ports

Outputs

PortDomainDescription
P powersignalInstantaneous power, in watts.

Conserving terminals

PortDomainDescription
i+ pcelectricalCurrent path in. Current into pc is counted as positive.
i− ncelectricalCurrent path out. Held at the same voltage as pc.
v+ pvelectricalPositive voltage-sensing pin. Draws no current.
v− nvelectricalNegative voltage-sensing pin. Draws no current.

Equations

pc.v = nc.v, pc.i + nc.i = 0
pv.i = nv.i = 0
power = pc.i · (pv.v − nv.v)

Implementation

Instantiates Modelica.Electrical.Analog.Sensors.PowerSensor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Instantaneous value only; for average power, filter or integrate the output.

Tips

  • To measure the power taken by a load, put pc–nc in series with it and connect pv and nv across it.
