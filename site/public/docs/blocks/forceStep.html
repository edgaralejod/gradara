Force step

A force step at a given time.

Description

Applies an offset force that steps up by a fixed amount at the step time.

Ports

Conserving terminals

PortDomainDescription
shaft flangetranslationalFlange the force acts on.

Parameters

ParameterDefaultDescription
Step stepForce1 NHeight of the step, in newtons. Negative values act as a load.
Offset offsetForce0 NForce before the step, in newtons.
Step time startTime0.5 s
≥ 0		Time of the step, in seconds.

Equations

F = offsetForce + (0 for time < startTime, stepForce afterward)
flange.f = −F

Implementation

Instantiates Modelica.Mechanics.Translational.Sources.ForceStep from the Modelica Standard Library 4.1.0. MSL documentation
