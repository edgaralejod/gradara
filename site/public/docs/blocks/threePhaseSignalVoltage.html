Block reference/3-phase

Controlled 3-phase voltage

Three phase voltages equal to the three input signals, from abc− to abc: an ideal (averaged) voltage-source inverter.

  • signal
  • 3-phase
  • Modelica Standard Library
  • 5 ports

Description

Three controlled voltage sources, one per phase, each equal to its input signal (the Modelica library polyphase signal voltage). Phase k acts between phase k of plug_n and phase k of plug_p.

It is the ideal model of a voltage-source inverter: the averaged output without switching ripple, dead time, or a DC-bus limit. Use it with Inverse Clarke transform in a field-oriented drive.

Example

Clarke and Park transforms Balanced three-phase signals become a rotating α, β pair, then constant d and q, and go back out through a controlled three-phase source.

Ports

Inputs 3

  • avasignal · V

    Phase a voltage command, in volts.

  • bvbsignal · V

    Phase b voltage command, in volts.

  • cvcsignal · V

    Phase c voltage command, in volts.

Conserving terminals 2

  • abcplug_p3-phase

    Three-phase output plug (phases a, b, c).

  • abc−plug_n3-phase

    Three-phase return plug: the negative terminal of each phase source. Connect a Star point to it for a neutral.

Equations

Modelica
plug_p.k.v − plug_n.k.v = vk for k = a, b, c

Implementation

Modelica Standard Library 4.1.0Modelica.Electrical.Polyphase.Sources.SignalVoltage
MSL documentation

Assumptions and limitations

  • Ideal: no internal impedance, no switching, no limit on the voltage it can produce. Limit the commands upstream (the current controllers’ limits, or Saturation) to model a finite DC bus.

Tips

  • Ground the star point on plug_n; the machine’s star point on plug_sn can share it.
