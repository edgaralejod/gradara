Temperature source

Holds its port at the input temperature (K).

Description

Holds its port at the temperature given by an input signal, supplying or absorbing whatever heat flow that takes.

Ports

Inputs

PortDomainDescription
TsignalTemperature to impose, in kelvin.

Conserving terminals

PortDomainDescription
T portthermalHeat port held at the input temperature.

Equations

port.T = T

Implementation

Instantiates Modelica.Thermal.HeatTransfer.Sources.PrescribedTemperature from the Modelica Standard Library 4.1.0. MSL documentation

Tips

  • The input is in kelvin. Add 273.15 to a Celsius signal.
