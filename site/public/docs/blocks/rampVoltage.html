Ramp voltage

Voltage ramp from offset to offset + V.

Description

An ideal voltage source that holds Offset until Start time, rises linearly by V over Duration, then stays at Offset + V.

Ports

Conserving terminals

PortDomainDescription
+ pelectricalPositive terminal.
− nelectricalNegative terminal.

Parameters

ParameterDefaultDescription
Height V12 VTotal rise, in volts. Negative values ramp down.
Duration duration1 s
≥ 0		Time taken to rise, in seconds. Must be greater than 0.
Offset offset0 VVoltage before the ramp, in volts.
Start time startTime0 s
≥ 0		Time the ramp starts, in seconds. 0 or more.

Equations

p.v − n.v = offset for time < startTime
p.v − n.v = offset + V · (time − startTime) / duration for startTime ≤ time < startTime + duration
p.v − n.v = offset + V afterward
p.i + n.i = 0

Implementation

Instantiates Modelica.Electrical.Analog.Sources.RampVoltage from the Modelica Standard Library 4.1.0. MSL documentation

Tips

  • Use it for soft-start supplies that would otherwise charge capacitors with a current spike.
