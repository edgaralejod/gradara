Block reference › 3-phase

Delta connection

Connects the phases in delta (a–b, b–c, c–a).

Description

Connects three single-phase elements in delta. Wire the elements’ plug_p to the line and to this block’s plug_p, and their plug_n to this block’s plug_n. Element a then sits between lines a and b, b between b and c, and c between c and a.

Ports

Conserving terminals

PortDomainDescription
abc plug_p3-phaseThree-phase plug in order a, b, c.
bca plug_n3-phaseThree-phase plug in order b, c, a: its phase a is joined to phase b of plug_p, and so on.

Equations

plug_n.a = plug_p.b, plug_n.b = plug_p.c, plug_n.c = plug_p.a (same potential and current balance)

Implementation

Instantiates Modelica.Electrical.Polyphase.Basic.Delta from the Modelica Standard Library 4.1.0. MSL documentation
