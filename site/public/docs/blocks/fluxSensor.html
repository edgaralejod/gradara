Flux sensor

Magnetic flux through the sensor.

Description

Measures the magnetic flux through it. Insert it in series in the flux path; it has no magnetic potential drop.

Ports

Outputs

PortDomainDescription
PhisignalFlux from port_p to port_n through the sensor, in webers.

Conserving terminals

PortDomainDescription
+ port_pmagneticPositive magnetic port.
− port_nmagneticNegative magnetic port.

Equations

Phi = port_p.Φ
port_p.V_m = port_n.V_m

Implementation

Instantiates Modelica.Magnetic.FluxTubes.Sensors.MagneticFluxSensor from the Modelica Standard Library 4.1.0. MSL documentation
