Switch (logic)

Outputs u1 while u2 is true, otherwise u3.

Description

Selects between two Real signals with a Boolean input: the output follows u1 while u2 is true, otherwise u3.

Ports

Inputs

PortDomainDescription
sel u2BooleanBoolean selector.
true u1signalReal input passed through while u2 is true.
false u3signalReal input passed through while u2 is false.

Outputs

PortDomainDescription
ysignalSelected signal.

Equations

y = u1 if u2, otherwise u3

Implementation

Instantiates Modelica.Blocks.Logical.Switch from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The switchover is instantaneous, so y jumps when u1 and u3 differ.

Tips

  • To select by comparing a Real control signal with a threshold instead, use Switch.
