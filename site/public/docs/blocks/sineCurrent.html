AC current

Sinusoidal current source.

Description

An ideal sinusoidal current source with amplitude, frequency, phase, and DC offset.

Ports

Conserving terminals

PortDomainDescription
+ pelectricalPositive pin. The source current flows into p, through the source, and out of n.
− nelectricalNegative pin.

Parameters

ParameterDefaultDescription
Amplitude I1 APeak amplitude, in amperes.
Frequency f50 Hz
≥ 0		Frequency, in Hz. 0 or more.
Phase phase0 radPhase at time 0, in radians.
Offset offset0 ADC offset, in amperes.

Equations

p.i = offset + I · sin(2π · f · time + phase)
p.i + n.i = 0

Implementation

Instantiates Modelica.Electrical.Analog.Sources.SineCurrent from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No voltage limit. The wave starts at time 0; there is no start time.

Tips

  • As with DC current, a positive value pushes current out of n into the circuit.
