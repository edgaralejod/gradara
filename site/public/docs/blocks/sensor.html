Block reference › Rotational

Speed sensor

Measures shaft speed without loading the mechanical system.

Description

Measures the absolute angular velocity of the flange without loading it.

Ports

Outputs

PortDomainDescription
out ysignalAngular velocity, in rad/s.

Conserving terminals

PortDomainDescription
shaft flangerotationalMeasured flange. No torque is exchanged.

Equations

y = d(flange.phi)/dt
flange.tau = 0

Implementation

The block’s Modelica equations:

y = der(flange.phi);
flange.tau = 0;

Assumptions and limitations

  • Ideal: no noise, delay, or resolution limit.

Examples

Used in the shipped examples Motor speed control. Open them from Examples in the app.
