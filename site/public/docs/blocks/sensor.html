Block reference/Rotational

Speed sensor

Measures shaft speed without loading the mechanical system.

  • signal
  • rotational
  • Gradara equations
  • 2 ports

Description

Measures the absolute angular velocity of the flange without loading it.

Example

Clutch, backlash, and rotational sources A clutch that locks, gear backlash, a spring-damper coupling, and a load that steps its torque.

Ports

Outputs 1

  • outysignal

    Angular velocity, in rad/s.

Conserving terminals 1

  • shaftflangerotational

    Measured flange. No torque is exchanged.

Equations

Modelica

flange.tau = 0

Implementation

The block’s Modelica model
y = der(flange.phi);
flange.tau = 0;

Assumptions and limitations

  • Ideal: no noise, delay, or resolution limit.
