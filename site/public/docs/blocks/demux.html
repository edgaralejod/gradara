Demux

Split a drawing path into three. Same stand-in as Mux until buses exist.

Description

A drawing stand-in for splitting a bundled line into three signals, the counterpart of Mux.

Models containing Demux cannot run: model checks report it as a drawing-only block, and Run refuses the model until it is replaced by direct connections.

Ports

Inputs

PortDomainDescription
usignalBundled line, usually from a Mux.

Outputs

PortDomainDescription
1 y1signalFirst output, a copy of u.
2 y2signalSecond output, a copy of u.
3 y3signalThird output, a copy of u.

Equations

y1 = u
y2 = u
y3 = u

Implementation

The block’s Modelica equations:

y1 = u;
y2 = u;
y3 = u;

Assumptions and limitations

  • No vector or bus signals: every output repeats the one input signal.
  • Always three outputs.
