Ramp

A linearly increasing signal after a start time.

Description

Outputs zero until Start time, then rises in a straight line at Slope per second without limit.

Ports

Outputs

PortDomainDescription
ysignalOutput signal: 0 before Start time, then Slope · (time − Start time).

Parameters

ParameterDefaultDescription
Slope slope1 1/sRate of rise, in units per second. Negative values ramp down.
Start time startTime0 s
≥ 0		Time the ramp starts, in seconds. 0 or more.

Equations

y = 0 for time < startTime
y = slope · (time − startTime) for time ≥ startTime

Implementation

The block’s Modelica equations:

y = if time < startTime then 0 else slope*(time-startTime);

Assumptions and limitations

  • The ramp never levels off. To stop it at a value, follow it with Saturation.

Examples

Used in the shipped examples EV drivetrain, 480 VAC → 24 VDC flyback. Open them from Examples in the app.
