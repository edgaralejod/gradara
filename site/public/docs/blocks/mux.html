Mux

Three signals into one drawing path. Vector buses come later; this keeps the sheet readable.

Description

A drawing stand-in for bundling three signals into one line. Gradara has no vector buses yet, so this block only keeps a sheet readable.

Models containing Mux cannot run: model checks report it as a drawing-only block, and Run refuses the model until it is replaced by direct connections.

Ports

Inputs

PortDomainDescription
1 u1signalFirst signal.
2 u2signalSecond signal.
3 u3signalThird signal.

Outputs

PortDomainDescription
ysignalBundled line, drawn to a Demux.

Equations

y = u1 (u2 and u3 are not carried)

Implementation

The block’s Modelica equations:

y = u1 + 0*u2 + 0*u3;

Assumptions and limitations

  • No vector or bus signals: the output carries only u1, and u2 and u3 are dropped.
  • Always three inputs.
