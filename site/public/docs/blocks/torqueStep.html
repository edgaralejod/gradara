Torque step

A torque step at a given time.

Description

Applies an offset torque that steps up by a fixed amount at the step time. Use it as a load disturbance.

Ports

Conserving terminals

PortDomainDescription
shaft flangerotationalFlange the torque acts on.

Parameters

ParameterDefaultDescription
Step stepTorque1 N·mHeight of the step, in N·m. Negative values act as a load.
Offset offsetTorque0 N·mTorque before the step, in N·m.
Step time startTime0.5 s
≥ 0		Time of the step, in seconds.

Equations

τ = offsetTorque + (0 for time < startTime, stepTorque afterward)
flange.tau = −τ

Implementation

Instantiates Modelica.Mechanics.Rotational.Sources.TorqueStep from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The step is instantaneous and does not depend on speed or direction.
