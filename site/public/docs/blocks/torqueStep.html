Torque step

A torque step at a given time.

  • rotational
  • Modelica Standard Library
  • 1 port
  • 3 parameters

Description

Applies an offset torque that steps up by a fixed amount at the step time. Use it as a load disturbance.

Example

Rotational drivetrain A torque step drives a motor inertia through a 2:1 gear and a shaft spring into a damped load, with every rotational sensor.

Also in this example:Torque sensorFixed (rotational)Torsion springTorsion damperInertia (ideal)Ideal gearSpeed sensor (ideal)Acceleration sensorPower sensor (rotational)Relative speed sensor

Ports

  • shaftflangerotational

    Flange the torque acts on.

Parameters

  • StepstepTorque1 N·m

    Height of the step, in N·m. Negative values act as a load.

  • OffsetoffsetTorque0 N·m

    Torque before the step, in N·m.

  • Step timestartTime0.5 s

    ≥ 0

    Time of the step, in seconds.

Equations

Modelica
τ = offsetTorque + (0 for time < startTime, stepTorque afterward)
flange.tau = −τ

Implementation

Assumptions and limitations

  • The step is instantaneous and does not depend on speed or direction.
