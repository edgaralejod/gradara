Rack and pinion

Ideal rack and pinion: rotation to translation by a fixed ratio.

Description

An ideal rack and pinion, or any ideal rotary-to-linear transmission. The rotational flange turns ratio radians per meter of travel of the translational flange.

Ports

Conserving terminals

PortDomainDescription
rot flangeRrotationalRotational flange (the pinion). Torque into it is positive.
lin flangeTtranslationalTranslational flange (the rack). Force into it is positive.

Parameters

ParameterDefaultDescription
Ratio ratio100 rad/mTransmission ratio flangeR.phi/flangeT.s, in rad/m. For a pinion of radius r, ratio = 1/r. A negative value reverses direction.

Equations

flangeR.phi = ratio · flangeT.s
0 = ratio · flangeR.tau + flangeT.f

Implementation

Instantiates Modelica.Mechanics.Rotational.Components.IdealGearR2T from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No mass, inertia, friction, backlash, or elasticity.
