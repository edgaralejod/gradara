Second-order

A second-order transfer function ωn² / (s² + 2ζωn s + ωn²).

Description

A second-order low-pass system with unity DC gain, set by natural frequency ωn and damping ratio ζ. Use it to model a sensor, actuator, or loop with an oscillatory response.

Ports

Inputs

PortDomainDescription
usignalInput signal.

Outputs

PortDomainDescription
ysignalOutput signal.

Parameters

ParameterDefaultDescription
Natural frequency wn10 rad/s
≥ 0.01		Natural frequency ωn, in rad/s. At least 0.01.
Damping ratio zeta0.7
≥ 0		Damping ratio ζ. 0 or more: below 1 the step response overshoots, 1 is critically damped, above 1 is overdamped, and 0 oscillates without decay.

Equations

dx1/dt = x2
dx2/dt = wn² · (u − x1) − 2 · zeta · wn · x2
y = x1, with x1 = x2 = 0 at time 0
Transfer function: wn² / (s² + 2 · zeta · wn · s + wn²)

Implementation

The block’s Modelica equations:

Real x1(start=0, fixed=true);
Real x2(start=0, fixed=true);
der(x1) = x2;
der(x2) = wn*wn*(u - x1) - 2*zeta*wn*x2;
y = x1;

Assumptions and limitations

  • Both states start at 0.
