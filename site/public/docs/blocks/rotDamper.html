Torsion damper

Linear rotational damper: τ = d·ω_rel.

Description

A linear viscous damper between two flanges: the torque is proportional to the relative speed. Connect it to Fixed (rotational) for friction to the housing.

Ports

Conserving terminals

PortDomainDescription
a flange_arotationalFlange a. Receives −τ.
b flange_brotationalFlange b. Receives τ, the damping torque.

Parameters

ParameterDefaultDescription
Damping d1 N·m·s/rad
≥ 0		Damping coefficient, in N·m·s/rad. Zero or positive.

Equations

ω_rel = d(flange_b.phi − flange_a.phi)/dt
τ = d · ω_rel
flange_b.tau = τ, flange_a.tau = −τ

Implementation

Instantiates Modelica.Mechanics.Rotational.Components.Damper from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Purely viscous: no Coulomb friction or stiction.
