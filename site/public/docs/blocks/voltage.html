Voltage drive

An ideal voltage source driven by a control signal.

Description

An ideal voltage source whose voltage equals its input signal. It behaves the same as Controlled voltage, with the input on the left.

Ports

Inputs

PortDomainDescription
in usignalCommanded voltage p.v − n.v, in volts.

Conserving terminals

PortDomainDescription
+ pelectricalPositive terminal.
− nelectricalNegative terminal.

Equations

p.v − n.v = u
p.i + n.i = 0

Implementation

The block’s Modelica equations:

v = u;

Assumptions and limitations

  • No internal resistance or current limit. The voltage follows the input instantly.

Tips

  • Typical use: a controller output driving DC motor.

Examples

Used in the shipped examples Motor speed control, 480 VAC → 24 VDC flyback, Servo position control. Open them from Examples in the app.
