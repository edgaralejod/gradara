Divide

Divide two signals: y = a / b. Keep the denominator away from zero.

Description

Divides the first input by the second.

Ports

Inputs

PortDomainDescription
asignalNumerator.
bsignalDenominator.

Outputs

PortDomainDescription
ysignalOutput signal, a / b.

Equations

y = a / b

Implementation

The block’s Modelica equations:

y = a / b;

Assumptions and limitations

  • The denominator is not guarded. If b reaches 0 during a run, the division fails and the simulation stops with an error.

Tips

  • If b can pass through zero, keep it away from zero first, for example with Max against a small constant or with Saturation.
