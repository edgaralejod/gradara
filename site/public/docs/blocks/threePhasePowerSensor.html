3-phase power sensor

Total instantaneous power of the three phases.

Description

Measures the total instantaneous power of a three-phase circuit. The current path pc–nc goes in series; the voltage path pv–nv goes across the element.

Ports

Outputs

PortDomainDescription
P powersignalTotal instantaneous power, in watts.

Conserving terminals

PortDomainDescription
i+ pc3-phaseCurrent path input (phases a, b, c). Current enters here.
i− nc3-phaseCurrent path output (phases a, b, c). Zero voltage drop from pc.
v+ pv3-phaseVoltage path positive plug (phases a, b, c). Draws no current.
v− nv3-phaseVoltage path reference plug (phases a, b, c). Draws no current.

Equations

power = Σ (pv.k.v − nv.k.v) · pc.k.i, summed over k = a, b, c

Implementation

Instantiates Modelica.Electrical.Polyphase.Sensors.PowerSensor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Instantaneous power only; for average or reactive power, filter or process the output.

Tips

  • For power into a load: pc on the source side, nc to the load, pv to the load’s phases, nv to its star point or return.
