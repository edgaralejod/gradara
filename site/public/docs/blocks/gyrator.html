Gyrator

Ideal gyrator: i1 = G2·v2, i2 = −G1·v1.

Description

An ideal gyrator: the current at each port is set by the voltage at the other. It turns a capacitor on one side into an inductance on the other, and conserves power when G1 = G2.

Ports

Conserving terminals

PortDomainDescription
1+ p1electricalPort 1 positive pin. Current into p1 is i1.
1− n1electricalPort 1 negative pin.
2+ p2electricalPort 2 positive pin. Current into p2 is i2.
2− n2electricalPort 2 negative pin.

Parameters

ParameterDefaultDescription
Gyration conductance 1 G11 SGyration conductance from port 1 voltage to port 2 current, in siemens.
Gyration conductance 2 G21 SGyration conductance from port 2 voltage to port 1 current, in siemens.

Equations

v1 = p1.v − n1.v, i1 = p1.i, p1.i + n1.i = 0
v2 = p2.v − n2.v, i2 = p2.i, p2.i + n2.i = 0
i1 = G2 · v2
i2 = −G1 · v1

Implementation

Instantiates Modelica.Electrical.Analog.Basic.Gyrator from the Modelica Standard Library 4.1.0. MSL documentation

Tips

  • A capacitor C on port 2 appears at port 1 as an inductance C / (G1 · G2).
