Thermal resistor

Linear thermal resistance: ΔT = R·Q.

Description

Linear thermal resistance between two ports with no heat storage: the temperature difference is proportional to the heat flow. Equivalent to Thermal conductor with G = 1 / R.

Ports

Conserving terminals

PortDomainDescription
a port_athermalHeat port a. Heat flow Q from a to b enters here.
b port_bthermalHeat port b. Q leaves here.

Parameters

ParameterDefaultDescription
Resistance R1 K/W
≥ 0		Thermal resistance, in K/W. Use a positive value.

Equations

ΔT = port_a.T − port_b.T
ΔT = R · Q
port_a.Q_flow = Q, port_b.Q_flow = −Q

Implementation

Instantiates Modelica.Thermal.HeatTransfer.Components.ThermalResistor from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Constant resistance, independent of temperature. No heat storage.

Tips

  • Datasheet junction-to-case and case-to-ambient values in K/W can be entered directly and chained in series.
