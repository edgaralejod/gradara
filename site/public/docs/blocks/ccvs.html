Current-controlled voltage source

Linear controlled source: v2 = R·i1.

Description

A linear current-controlled voltage source. Port 1 is a short circuit that senses its current; port 2 is an ideal voltage source proportional to that current.

Ports

Conserving terminals

PortDomainDescription
1+ p1electricalControl input, positive pin. The sensed current i1 flows into p1.
1− n1electricalControl input, negative pin. Held at the same voltage as p1.
2+ p2electricalOutput, positive pin.
2− n2electricalOutput, negative pin.

Parameters

ParameterDefaultDescription
Transresistance transResistance1 ΩTransresistance, in ohms. Any real number.

Equations

i1 = p1.i, p1.i + n1.i = 0
p1.v = n1.v
v2 = p2.v − n2.v, p2.i + n2.i = 0
v2 = transResistance · i1

Implementation

Instantiates Modelica.Electrical.Analog.Basic.CCV from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • Ideal: zero input and output impedance, unlimited output.
