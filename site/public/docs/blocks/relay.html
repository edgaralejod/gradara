Relay

A two-level relay.

Description

A two-level switch: the output is On value when the input is at or above Switch level, and Off value below it.

Ports

Inputs

PortDomainDescription
usignalInput signal.

Outputs

PortDomainDescription
ysignalOutput signal: On value or Off value.

Parameters

ParameterDefaultDescription
On value onValue1Output when u ≥ Switch level.
Off value offValue-1Output when u < Switch level.
Switch level offSwitch0The input level where the output switches, in both directions.

Equations

y = onValue if u ≥ offSwitch
y = offValue if u < offSwitch

Implementation

The block’s Modelica equations:

y = if u >= offSwitch then onValue else offValue;

Assumptions and limitations

  • No hysteresis: the block switches at one level both ways, so a noisy input near that level makes the output chatter and can slow the solver. For a band, use Boolean hysteresis or On-off controller.
