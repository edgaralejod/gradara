Switch

Pass u₁ when the control is above threshold, otherwise u₂.

Description

Passes one of two inputs depending on a control signal: u₁ when the control is at or above Threshold, otherwise u₂.

Ports

Inputs

PortDomainDescription
u₁ u1signalInput passed when sel ≥ Threshold.
selsignalControl signal compared with Threshold.
u₂ u3signalInput u₂, passed when sel < Threshold.

Outputs

PortDomainDescription
ysignalOutput signal.

Parameters

ParameterDefaultDescription
Threshold threshold0Level the control signal is compared with. The upper input is chosen when sel equals it.

Equations

y = u1 if sel ≥ threshold
y = u3 otherwise

Implementation

The block’s Modelica equations:

y = if sel >= threshold then u1 else u3;

Assumptions and limitations

  • The switch is instant, so the output jumps when the selection changes. It takes a real-valued control; for a Boolean control, use Logical switch.
