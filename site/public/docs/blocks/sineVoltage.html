AC voltage

Sinusoidal voltage: offset + V·sin(2πf·t + phase).

Description

An ideal sinusoidal voltage source with amplitude, frequency, phase, and DC offset. Use it for AC mains and test signals.

Ports

Conserving terminals

PortDomainDescription
+ pelectricalPositive terminal.
− nelectricalNegative terminal.

Parameters

ParameterDefaultDescription
Amplitude V325 VPeak amplitude, in volts. The default 325 V is the peak of 230 V RMS.
Frequency f50 Hz
≥ 0		Frequency, in Hz. 0 or more.
Phase phase0 radPhase at time 0, in radians.
Offset offset0 VDC offset, in volts.

Equations

p.v − n.v = offset + V · sin(2π · f · time + phase)
p.i + n.i = 0

Implementation

Instantiates Modelica.Electrical.Analog.Sources.SineVoltage from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No internal impedance. The wave starts at time 0; there is no start time.

Tips

  • V is the peak value: for a given RMS voltage, set V = √2 · V_rms.
