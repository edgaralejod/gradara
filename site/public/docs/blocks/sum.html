Sum

Adds two signals.

Description

Adds two signals.

Ports

Inputs

PortDomainDescription
+ asignalFirst input, added.
+ bsignalSecond input, added.

Outputs

PortDomainDescription
ysignalOutput signal, a + b.

Equations

y = a + b

Implementation

The block’s Modelica equations:

y = a + b;

Assumptions and limitations

  • Exactly two inputs, both added. To subtract, use Subtract; for more inputs, chain Sum blocks.

Used in the shipped examples PMSM · Field-oriented control. Open them from Examples in the app.
