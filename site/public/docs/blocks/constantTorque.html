Constant torque

A constant torque, independent of speed.

Description

Applies a constant torque to the flange, independent of speed and direction.

Ports

Conserving terminals

PortDomainDescription
shaft flangerotationalFlange the torque acts on.

Parameters

ParameterDefaultDescription
Torque tau_constant1 N·mThe torque, in N·m. A positive value accelerates the flange in the positive direction; a negative value acts as a load.

Equations

flange.tau = −tau_constant

Implementation

Instantiates Modelica.Mechanics.Rotational.Sources.ConstantTorque from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The torque does not reverse with speed: a negative value used as a load drives an unpowered shaft backward instead of holding it.
