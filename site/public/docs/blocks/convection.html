Convection

Convective heat transfer with the input conductance Gc.

Description

Convective heat transfer between a solid surface and a fluid, with the conductance given by an input signal. Use it when the heat transfer coefficient depends on flow speed or another computed quantity.

Ports

Inputs

PortDomainDescription
GcsignalConvective conductance h · A, in W/K.

Conserving terminals

PortDomainDescription
solidthermalHeat port at the solid surface. Heat flow Q from solid to fluid enters here.
fluidthermalHeat port at the fluid. Q leaves here.

Equations

ΔT = solid.T − fluid.T
Q = Gc · ΔT
solid.Q_flow = Q, fluid.Q_flow = −Q

Implementation

Instantiates Modelica.Thermal.HeatTransfer.Components.Convection from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • No heat storage in the boundary layer. The fluid is a single temperature.

Tips

  • For a constant coefficient, feed Gc from a Constant block.
