Hysteresis

True above uHigh, false below uLow, unchanged in between.

Description

A Schmitt trigger: the output turns true when the input rises above uHigh and turns false only when it falls below uLow. Between the two thresholds it keeps its previous value.

The output starts false.

Ports

Inputs

PortDomainDescription
usignalReal input.

Outputs

PortDomainDescription
yBooleanBoolean output.

Parameters

ParameterDefaultDescription
Lower threshold uLow0Lower threshold. When y is true and u < uLow, y becomes false. Must be less than uHigh.
Upper threshold uHigh1Upper threshold. When y is false and u > uHigh, y becomes true. Must be greater than uLow.

Equations

y = (¬y⁻ ∧ u > uHigh) ∨ (y⁻ ∧ u ≥ uLow)
y⁻ is the value just before the current event; y⁻ = false at t = 0.

Implementation

Instantiates Modelica.Blocks.Logical.Hysteresis from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The simulation stops with an error unless uHigh > uLow.

Tips

  • For a thermostat-style loop around a moving setpoint, On-off controller expresses the band relative to a reference signal.
