Op-amp (limited)

Op-amp with finite gain and output limited to the supply rails.

Description

An operational amplifier with finite open-loop gain whose output voltage is clipped to the supply rails. Use it where saturation matters, such as comparators or loops that can hit the rails.

Ports

Conserving terminals

PortDomainDescription
+ in_pelectricalNon-inverting input. Draws no current.
− in_nelectricalInverting input. Draws no current.
outelectricalOutput pin, an ideal voltage source to Ground. Its current is unconstrained.

Parameters

ParameterDefaultDescription
Open-loop gain V015000
≥ 0		Open-loop voltage gain, dimensionless. 0 or more.
Positive supply Vps15 VPositive supply rail, in volts: the highest output voltage.
Negative supply Vns-15 VNegative supply rail, in volts: the lowest output voltage. Set it below Vps.

Equations

v_in = in_p.v − in_n.v
in_p.i = 0, in_n.i = 0
out.v = min(Vps, max(Vns, V0 · v_in))

Implementation

Instantiates Modelica.Electrical.Analog.Ideal.IdealizedOpAmpLimited from the Modelica Standard Library 4.1.0. MSL documentation

Assumptions and limitations

  • The rails are fixed values, not pins; the block draws no supply current in the circuit.
  • No bandwidth, slew rate, offset, or output current limit. Saturation is a hard clip.
