Manual switch

Pick an input with a parameter. 1 uses the top input.

Description

Passes one of two inputs chosen by a parameter. Use it to try alternatives between runs without rewiring.

Ports

Inputs

PortDomainDescription
1 u1signalInput 1, passed when Select is 1.
2 u2signalInput 2, passed when Select is 2.

Outputs

PortDomainDescription
ysignalOutput signal.

Parameters

ParameterDefaultDescription
Select 1 or 2 sel1
≥ 1		Which input to pass: 1 or 2. Values below 1.5 select input 1; 1.5 and above select input 2.

Equations

y = u2 if sel ≥ 1.5
y = u1 otherwise

Implementation

The block’s Modelica equations:

y = if sel >= 1.5 then u2 else u1;

Assumptions and limitations

  • The choice is fixed during a run. To switch during a run, use Switch.

Tips

  • Both inputs must still be connected: an unconnected input is an error even when it is not selected.
