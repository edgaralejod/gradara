Discrete integrator

Sampled integrator accumulating the current input at each sample.

Description

A sampled integrator. At each sample instant it adds Ts times the current input to its state, a backward-Euler sum.

Ports

Inputs

PortDomainDescription
usignalInput signal, read at each sample instant.

Outputs

PortDomainDescription
ysignalOutput signal, the accumulated sum, held between samples.

Parameters

ParameterDefaultDescription
Sample period Ts0.001 s
≥ 0.0001		Sample period, in seconds. At least 0.0001 s (default 1 ms).

Equations

At t = k · Ts, k = 0, 1, 2, …:
x[k] = x[k − 1] + Ts · u[k], with x = 0 before the first sample
y = x

Implementation

The block’s Modelica equations:

discrete Real x(start=0, fixed=true);
when sample(0, Ts) then
  x = pre(x) + Ts*u;
end when;
y = x;

Assumptions and limitations

  • No output limits, reset, or initial-value setting. The state starts at 0.
  • Samples are taken at fixed multiples of Ts from time 0.
