Sine wave

A continuous sinusoid.

Description

A continuous sinusoid with adjustable amplitude, frequency in hertz, phase, and offset.

Ports

Outputs

PortDomainDescription
ysignalOutput signal.

Parameters

ParameterDefaultDescription
Amplitude amplitude1Peak deviation from Offset. A negative value inverts the wave.
Frequency frequency1 Hz
≥ 0		Frequency, in Hz (cycles per second, not rad/s). 0 or more; 0 gives the constant offset + amplitude · sin(phase).
Phase phase0 radPhase at time 0, in radians.
Offset offset0Value the wave oscillates around.

Equations

y = offset + amplitude · sin(2π · frequency · time + phase)

Implementation

The block’s Modelica equations:

y = offset + amplitude*sin(6.283185307179586*frequency*time + phase);

Assumptions and limitations

  • The wave runs from time 0; there is no start time.

Tips

  • For a cosine, set Phase to π/2 (1.5708).

Examples

Used in the shipped examples 480 VAC → 24 VDC flyback. Open them from Examples in the app.
