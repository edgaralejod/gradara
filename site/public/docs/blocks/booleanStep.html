Boolean step

False before the step time, true after.

Description

Outputs false before the step time and true from then on. Use it to enable part of a model partway through a run.

Ports

Outputs

PortDomainDescription
yBooleanFalse for t < startTime, true for t ≥ startTime.

Parameters

ParameterDefaultDescription
Step time startTime0.5 s
≥ 0		Time of the step, in seconds, 0 or more. At 0 the output is true from the start.

Equations

y = t ≥ startTime

Implementation

Instantiates Modelica.Blocks.Sources.BooleanStep from the Modelica Standard Library 4.1.0. MSL documentation

Tips

  • For a true-to-false step, follow it with NOT.
